# Telecom Site Parameters Sheet — نسخة الموقع (Static)

نفس التطبيق بنفس الشكل، بس بقى موقع عادي (HTML + JavaScript) من غير سيرفر بايثون.
كل حاجة (قراءة الإكسل، الدمج، البحث، الملاحظات) بتحصل **جوه المتصفح**، وبيانات الموقع **ماتتبعتش لأي مكان**.

## النشر على GitHub Pages

1. اعمل Repository جديد على GitHub (مثلًا `telecom-site`).
2. ارفع محتويات الفولدر ده كلها (`index.html` و`static/` وباقي الملفات) — من **Add file → Upload files** واسحب الفولدرات.
3. من **Settings → Pages**: اختار **Deploy from a branch**، والـ Branch `main`، والفولدر `/ (root)` ثم **Save**.
4. بعد دقيقة أو اتنين الموقع يفتح على:
   `https://اسم-حسابك.github.io/telecom-site/`

## الاستخدام

- ارفع ملف الإكسل من خانة **Data Source** (أو اسحبه في أي مكان في الصفحة). الصيغ: `.xlsx` `.xlsm` `.csv`.
- قواعد الرفع والأعمدة والبحث **زي النسخة القديمة بالظبط**: نفس الاسم يستبدل، اسم مختلف يتضاف ويتدمج، والأحدث يكسب لو نفس الـ Cell.
- تقدر تفتح موقع مباشرة برابط زي `...github.io/telecom-site/#9498`.
- البحث بيقبل الأرقام العربي (٩٤٩٨) كمان.

## مهم تعرفه

| الموضوع | التفاصيل |
|---|---|
| **مكان التخزين** | الملفات المرفوعة والملاحظات بتتحفظ في **متصفح الجهاز ده بس** (IndexedDB). تفضل بعد قفل الصفحة وإعادة فتحها. |
| **جهاز تاني / موبايل** | لازم ترفع الملف عليه هو كمان. الملاحظات مش بتنتقل بين الأجهزة. |
| **مسح بيانات المتصفح** | لو مسحت "Site data / Cookies" هتتمسح الملفات والملاحظات. |
| **Private / Incognito** | البيانات بتضيع أول ما تقفل التاب (والموقع بيحذّرك). |
| **الخصوصية** | الموقع نفسه عام على الإنترنت، لكن **ملفات الإكسل مش جواه**. ماترفعش ملف الإكسل على الـ Repository نفسه. |
| **ملفات كبيرة** | القراءة بتحصل في الخلفية فالصفحة ما بتهنجش، بس الملفات الضخمة (مئات الميجا) ممكن تاخد وقت وذاكرة. |
| **مفيش إنترنت** | بعد أول تحميل الموقع مش محتاج إنترنت؛ المكتبات والخط كلهم جوه الفولدر. |

## تجربة على الجهاز

- **أسهل طريقة:** دوس مرتين على `index.html`، هيشتغل مباشرة.
- أو من الترمنال جوه الفولدر: `python -m http.server 8000` وافتح `http://localhost:8000`.

## الملفات

```
index.html                 الصفحة
static/css/, static/fonts/ التصميم والخط
static/js/app.js           الواجهة
static/js/store.js         الدمج والبحث والتخزين (بديل data_store.py)
static/js/parser.js        قراءة الإكسل/CSV
static/js/parse-worker.js  قراءة الملف في الخلفية
static/js/vendor/          مكتبتين جاهزتين: SheetJS و dom-to-image (بدون CDN)
```
